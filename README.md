# OLX Clone Monorepo

Production-ready scaffold for an OLX-style marketplace platform:

- **Flutter mobile app** (`flutter_app`) with OLX-inspired UI structure
- **.NET 8 Web API** (`backend`) using clean architecture
- **PostgreSQL** with EF Core migrations
- **React Admin Dashboard** (`react_admin`)
- **SignalR chat**, **JWT auth**, **role-based access**

## Monorepo Structure

- `backend/` – .NET 8 API + application/domain/infrastructure layers
- `flutter_app/` – Flutter mobile UI and feature modules
- `react_admin/` – React + TypeScript + admin pages
- `docs/` – API contract, ER diagram, setup, deployment notes
